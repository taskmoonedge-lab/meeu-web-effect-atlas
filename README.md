# MEEU Web Effect Atlas

R&D catalog for reusable high-end web effect families.

## v0.7 data model

- **Family**: one implementation core
- **Variant**: alternate behavior/look using the same core
- **Preset**: art-direction parameter set

The previous 620 flat effect records are preserved as variants but consolidated into 315 effect families.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
